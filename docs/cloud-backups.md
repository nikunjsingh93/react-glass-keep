# Cloud backups have been replaced

Glass Keep 1.0.9 replaces Google Drive/OneDrive connections with **Automatic JSON export** in Settings. No provider registration is needed. Choose every **1, 7, or 30 days**, then sync the download folder yourself.

See the [automatic export and restore guide](automatic-exports.md), including where files are saved, browser limits and upgrade details. Existing JSON and ZIP backups can still be imported.
